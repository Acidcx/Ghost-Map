No machine dashboards yet

Ghost Map lays out a dashboard from the PLC's tags: alarms grouped by area, timers, counters and run state.

In Tags (OPC UA), connect to the gateway, select the controller or its fault folder, and press Build dashboard. Or press From CSV... above and pick a tag export. Type demo as the endpoint to try it on a simulated leveler.

Ghost Map reads each switch's port counters every poll interval (SNMP, read-only), whether or not this page is open, and keeps 7 days of rates and 90 days of events. Rates are averages over one interval, so a storm shorter than that shows up smaller than it was.

TSC database

Ghost Map reads the part schedule view with three fixed SELECT queries on a read-only connection. Use a SQL login that can only SELECT from the view's schema (for example GRANT SELECT ON SCHEMA::DataView TO ghostmap_ro). Type demo as the server to try a simulated schedule.
